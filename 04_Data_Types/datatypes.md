# Object Types / Data Types

- Number : 1234, 3.1415, 3+4j, 0b11, Decimal(), Fraction()

- String : 'spam', "Bob's", b'a\x01c'

- list : [1, 2, 3], [1, 2, 3, ['a', 'b']]

- Tuple : (1, 'spam', 4, 'U')

- Dictionary : {'food': 'spam', 'taste': 'yum'}

- Set: {'a', 'b', 'c'} [unique values only]

- File : open('eggs.txt')

- Boolean: True, False

- None: None

- Functions, modules, classes

- Advanced: Decorators, Generators, Iterators, MetaProgramming
